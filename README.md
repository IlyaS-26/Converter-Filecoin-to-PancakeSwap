# Converter-Filecoin-to-PancakeSwap

Сервис, который позволяет переводить монеты Filecoin (FIL) в PancakeSwap (CAKE) и наоборот.

## Работа с сервисом

На вход, в качестве запроса подается строка вида: ***число_(FIL|CAKE)***.

## Пример работы

|  запрос  |           ответ           |
|:--------:|:-------------------------:|
|  5 FIL   | 5,0000 FIL = 8,3911 CAKE  |
| 12 CAKE  | 12,0000 CAKE = 7,1810 FIL |
| 2.53 FIL | 2,5300 FIL = 4,2264 CAKE  |
